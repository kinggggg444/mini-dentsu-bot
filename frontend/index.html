Comment ça marche

Connectez votre WhatsApp en 3 étapes

01

Entrez votre numéro

Saisissez votre numéro WhatsApp avec l'indicatif international (ex: 33612345678 pour la France).

02

Récupérez le code de pairing

Un code à 8 chiffres est généré automatiquement. Copiez-le en un clic.

03

Liez dans WhatsApp

Dans WhatsApp → Appareils connectés → Lier un appareil → Entrez le code. Le bot est actif immédiatement.
